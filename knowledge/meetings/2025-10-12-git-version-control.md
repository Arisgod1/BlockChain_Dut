## 内容

本次例会介绍了 Git 的工作区、暂存区和版本库，并演示常用操作：

```bash
git add filename
git add .
git status
git commit -m "Commit message"
git push origin branch-name
```

协作流程包括 Fork 公共仓库、克隆个人仓库、在本地提交修改、推送分支和创建 Pull Request。

见面会部分介绍了小组希望保持扁平交流、关注成员个人发展、为不同节奏的人提供交流空间，并从可落实的目标开始推进工作。

# Content contract

Use `docs/content-authoring.md` for Markdown fields and type-specific sections. Use `docs/image-guidelines.md` for asset paths, naming, rights, alt text, EXIF, and dimensions.

Every document uses `schemaVersion: 1`, a globally stable ID, a type matching its directory, explicit authors, ISO dates, `cover`, and `media`. Drafts never publish. Archived entries remain public with a visible archived label.

Templates and examples are non-publishing. Keep examples structurally useful and subject-matter neutral.
